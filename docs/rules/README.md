# 规则库

## 目标

规则库是规则引擎的唯一规则来源。AI 只能在规则库允许的范围内发言和提交行动，不能直接修改对局状态或裁定胜负。

## 模块边界

| 模块 | 职责 | 不负责 |
|---|---|---|
| 角色定义 | 阵营、身份类型、技能与私有信息 | 玩家数量和角色组合 |
| 技能定义 | 触发时机、目标、资源、效果和阻断条件 | 整局流程推进 |
| 版型配置 | 人数、角色构成、警长规则和可选细则 | 模型如何发言 |
| 阶段流程 | 夜晚、白天、发言、投票和结算顺序 | 角色文案 |
| 结算规则 | 死亡原因、技能链和胜负优先级 | 前端展示 |
| 可见性策略 | 玩家、跟随视角和上帝视角的信息过滤 | 生成隐藏推理 |
| AI 行为契约 | 合法动作格式和角色扮演上下文 | 执行规则效果 |

## 扩展原则

1. 新角色通过新增角色与技能定义接入，不修改通用阶段代码。
2. 新版型通过组合已有角色和规则选项创建。
3. 狼美人、骑士等改变流程的角色通过事件与技能钩子扩展，不在角色名称上写条件分支。
4. 咒狐、丘比特等新阵营通过独立胜利条件扩展，不假定游戏只有好人和狼人。
5. 所有规则对象带稳定标识和版本号；历史对局绑定当时版本，升级规则不篡改旧回放。
6. 争议规则必须成为显式选项，禁止依靠主持人口头补丁。

## 目录约定

```text
docs/rules/
├── core/       # 通用术语、规则选项和结算约束
├── roles/      # 角色卡定义
└── rulesets/   # 人数、阵容与玩法配置
```

当前内容是经过确认的规则基线。机器可读格式将在规则对象模型审核后另行设计。

# 基础规则选项 v0.1

## 已确认默认值

| 规则项 | 默认值 |
|---|---|
| 女巫自救 | 禁止 |
| 女巫同夜双药 | 禁止 |
| 女巫刀口信息 | 解药尚未使用时可见 |
| 守卫自守 | 允许 |
| 守卫空守 | 允许 |
| 连续两夜守护同一玩家 | 禁止 |
| 同守同救 | 目标仍然死亡 |
| 守卫阻挡毒药 | 不阻挡 |
| 中毒后的猎人或狼王发动死亡技能 | 禁止 |
| 猎人或狼王放弃开枪 | 允许 |
| 白痴被放逐 | 翻牌免死，保留发言权，永久失去投票权 |
| 普通狼人自爆带人 | 禁止 |
| 狼王自爆带人 | 禁止 |
| 白狼王合法自爆带人 | 允许 |

## 配置归属

这些默认值不能散落在角色代码中。具体版型可以显式覆盖允许覆盖的选项；不可覆盖的核心约束由规则版本控制。

以下事项将在阶段流程设计时确定：

- 发言与投票的精确顺序
- 平票和再次平票的处理
- 遗言资格
- 自爆的合法时间窗口
- 死亡技能与胜负判定的结算优先级

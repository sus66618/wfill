# 基础角色卡 v0.1

## 通用字段

每张角色卡必须定义：稳定标识、显示名称、规则版本、阵营、身份类型、获胜条件引用、公开说明、私有信息、技能列表、行动阶段、目标限制、使用资源、触发条件、阻断条件、死亡交互、可见性和 AI 扮演提示。

角色卡不直接定义玩家人数、整局角色构成、警长流程、发言顺序或最终胜负算法；这些由版型和流程模块提供。

## 村民 `villager`

- 阵营：好人；类型：平民。
- 夜间无技能，只接收依法可见的公开信息。
- 白天可以发言和投票。
- 无特殊死亡效果。

## 普通狼人 `werewolf`

- 阵营：狼人；类型：普通狼。
- 夜间识别存活狼队友，进入狼人私密频道并共同决定刀杀目标，也可以空刀。
- 白天正常发言和投票，可以在版型规定的合法窗口自爆。
- 狼人密聊只对存活狼人和上帝视角可见。
- 无特殊死亡效果。

## 预言家 `seer`

- 阵营：好人；类型：神职。
- 每晚可以查验一名其他存活玩家。
- 默认只得到“好人阵营”或“狼人阵营”，不获得具体角色。
- 查验结果仅本人和上帝视角可见。
- 特殊角色可以通过查验结果修饰器改变结果。

## 女巫 `witch`

- 阵营：好人；类型：神职。
- 初始拥有一瓶解药和一瓶毒药，每瓶整局最多使用一次。
- 解药存在时，可以得知当夜狼人刀杀目标，并选择救下该目标。
- 不可使用解药自救；同一夜不可同时使用两瓶药。
- 毒药可以选择一名其他存活玩家，使其因中毒死亡。
- 守卫不能阻止毒药；中毒会阻止猎人和狼王的死亡技能。

## 猎人 `hunter`

- 阵营：好人；类型：神职。
- 被狼人刀杀或被白天放逐时，可以选择一名其他存活玩家开枪带走，也可以放弃。
- 被女巫毒杀或受到技能封锁时不能开枪。
- 开枪状态仅本人和上帝视角可见。

## 狼王 `wolf-king`

- 阵营：狼人；类型：功能狼。
- 继承普通狼人的夜间能力。
- 被放逐、被猎人带走或被狼队自刀时，可以选择一名其他存活玩家带走，也可以放弃。
- 被毒杀、主动自爆或受到技能封锁时不能带人。
- 与白狼王是两个独立角色，不使用模糊的共同名称代替。

## 白狼王 `white-wolf-king`

- 阵营：狼人；类型：功能狼。
- 继承普通狼人的夜间能力。
- 白天在版型允许的发言窗口，可以主动自爆并带走一名其他存活玩家。
- 技能结算后中止当前白天流程并进入后续规定阶段。
- 被放逐、被毒杀、被猎人带走或夜间死亡时不能发动带人技能。
- 最后一狼是否允许发动由版型和结算规则明确规定。

## 白痴 `idiot`

- 阵营：好人；类型：神职。
- 夜间无技能。
- 被白天投票放逐时自动翻牌并免疫该次放逐。
- 翻牌后保持存活和发言权，但永久失去投票权，也不能担任警长。
- 第二次被放逐时不再免疫；被夜间或其他技能杀死时正常死亡。

## 守卫 `guard`

- 阵营：好人；类型：神职。
- 每晚可以守护一名存活玩家，也可以自守或空守。
- 不能连续两个夜晚守护同一玩家，间隔一晚后可以再次守护。
- 守护阻止一次普通狼人刀杀，不阻止毒药、开枪、白狼王带人和白天放逐。
- 守护和女巫解药同时作用于同一个刀杀目标时，该目标仍然死亡。

# WFill MVP Implementation Roadmap

**Spec:** `docs/superpowers/specs/2026-08-22-ai-werewolf-design.md`

整体规格拆为四个顺序执行、分别验收的实施计划。每个阶段都必须形成可运行软件，禁止跨阶段提前堆空接口。

1. **规则内核与 6 人版型**：TypeScript 工程、运行时协议、确定性状态机、夜间技能、投票、平票、遗言、胜负和脚本完整对局。详细计划：`2026-08-22-rule-engine-foundation.md`。
2. **事件、投影与编排（已完成本地基线）**：SQLite 事件存储、审计快照恢复、公开/跟随/上帝投影、自动/单步/暂停编排、REST 与 SSE 续传。当前使用脚本控制器完成可重复验收。
3. **模型与提示词**：提供商适配器、固定提示词分层、结构化行动、发言预算、Token 统计、本地凭据引用和模拟/真实模型契约测试。
4. **UI 与完整验收**：React 三栏对局页、模型配置、创建对局、中央播报、左右座位、视角切换、回放、Playwright 和真实多模型验收。

阶段依赖严格单向：2 依赖 1，3 依赖 1 和 2，4 依赖 1 至 3。每阶段开始前根据已验证接口编写独立详细计划。
